# Day 5 - Context Engineering

## Objective
Understand how context affects AI-generated outputs.

## Activity

I tested two prompts:

### Prompt A (Without Context)
Requested a 30-day learning roadmap without providing any background information.

### Prompt B (With Context)
Requested the same roadmap but included:
- Current Situation: Student
- Current Skills: Python basics, prompt engineering basics, content creation, video editing
- Goal: Become an AI Engineer
- Available Time: 2 Hours/Day
- Experience Level: Beginner
- Preferred Learning Style: Projects & Videos

## Results

### Prompt A
Generated a generic roadmap suitable for any learner.

### Prompt B
Generated a personalized roadmap tailored to my skills, goals, learning style, and available time.

## Comparison

| Prompt A | Prompt B |
|-----------|-----------|
| Generic roadmap | Personalized roadmap |
| Broad recommendations | Goal-oriented recommendations |
| Not tailored to user | Tailored to user background |
| Less actionable | More practical and achievable |

## Key Learnings

- Context significantly improves AI outputs.
- Personalized information leads to more relevant recommendations.
- AI can provide better guidance when it understands goals and constraints.
- Context Engineering is one of the most powerful prompt engineering techniques.


## Conclusion

This exercise demonstrated that Context Engineering transforms generic AI responses into personalized and actionable outputs. The more relevant context provided, the more useful the AI-generated result becomes.
